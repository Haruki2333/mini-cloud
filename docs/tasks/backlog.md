# 任务清单 Backlog

> **怎么加任务**：在文末追加一个 `## T???` 块，状态写 `idea` 即可，AI 下次扫描时会自动分配 ID 并出方案。
>
> **怎么审核**：
> - 同意方案 → 把任务的状态字段从 `planned` 改成 `ok`
> - 否决任务 → 改成 `skip`
> - 让 AI 调整方案 → 不动状态字段，去 `plans/<id>.md` 末尾的 Feedback 区写一行反馈
>
> **状态值**：`idea` → `planned` → `ok` → `wip` → `done`，另有终止态 `skip`。详见 [README.md](README.md)。
