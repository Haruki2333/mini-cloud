# T001 丰富手牌录入的数据

## Context

当前手牌录入只记录桌型（6max/9max/hu）、位置、底注等结构化信息，缺少"线上/线下"和"桌面风格（紧凶/松浪）"这两个上下文维度。这两个字段对 AI 分析有价值：线下牌局和线上牌局的策略存在差异，桌面整体动态也影响最优打法。两个字段均设为可选，不破坏已有数据。

## 实现方案

### 步骤 1 — 数据库模型：新增两个 ENUM 字段

文件：`backend/services/poker-coach/models.js`

在 `table_type` 字段定义块之后、`hero_position` 块之前，插入两个字段定义：

```javascript
      table_location: {
        type: DataTypes.ENUM("online", "offline"),
        allowNull: true,
      },
      table_dynamic: {
        type: DataTypes.ENUM("tight_aggressive", "loose_passive"),
        allowNull: true,
      },
```

由于项目使用 `sync({ alter: true })`，启动时 Sequelize 会自动给已存在的 `poker_hands` 表 `ALTER TABLE ADD COLUMN`，不需要手写迁移。

### 步骤 2 — DAO 层：createHand 写入两个新字段

文件：`backend/services/poker-coach/dao.js`

在 `actions: fields.actions || null,` 之后、`is_analyzed: false,` 之前插入：

```javascript

```

### 步骤 3 — 手牌文本化：buildHandContext 输出新字段

文件：`backend/services/poker-coach/hand-context.js`

在 `` lines.push(`桌型: ${hand.table_type || "6max"}`); `` 之后、`` lines.push(`位置: ${hand.hero_position}`); `` 之前插入：

```javascript
  if (hand.table_location) {
    const locLabel = hand.table_location === "online" ? "线上" : "线下";
    lines.push(`拍桌: ${locLabel}`);
  }
  if (hand.table_dynamic) {
    const dynLabel = hand.table_dynamic === "tight_aggressive" ? "紧凶" : "松浪";
    lines.push(`桌面动态: ${dynLabel}`);
  }
```

### 步骤 6 — H5 前端 JS：新增两个 segmented 控件的 render/bind 函数

文件：`backend/demo/poker-coach/js/form.js`

在 `bindTableSeg` 函数结束之后，新增四个函数，风格与 `renderTableSeg`/`bindTableSeg` 保持一致：

```javascript
function renderLocationSeg() {
  $$("#locationSeg button").forEach(function (b) {
    b.classList.toggle("active", b.dataset.location === state.table_location);
  });
}

function bindLocationSeg() {
  $$("#locationSeg button").forEach(function (b) {
    b.addEventListener("click", function () {
      // 再次点击已选中项则取消选中
      state.table_location = (state.table_location === b.dataset.location) ? null : b.dataset.location;
      renderLocationSeg();
    });
  });
}

function renderDynamicSeg() {
  $$("#dynamicSeg button").forEach(function (b) {
    b.classList.toggle("active", b.dataset.dynamic === state.table_dynamic);
  });
}

function bindDynamicSeg() {
  $$("#dynamicSeg button").forEach(function (b) {
    b.addEventListener("click", function () {
      state.table_dynamic = (state.table_dynamic === b.dataset.dynamic) ? null : b.dataset.dynamic;
      renderDynamicSeg();
    });
  });
}
```

## 验证方式

1. **启动服务**：重启后端，观察 Sequelize `sync({ alter: true })` 日志中是否有 `ALTER TABLE poker_hands ADD COLUMN table_location` 和 `ADD COLUMN table_dynamic`（首次运行时）。

2. **H5 Demo 手动测试**：
   - 打开 `/poker/`，Step 0「局况」页「桌型」下方应出现「拍桌类型」和「桌面动态」两组 segmented 按钮，均初始无选中。
   - 点击「线上」变为 active；再次点击应取消（回到无选中）。
   - 提交表单，DevTools Network 面板确认 POST `/api/poker/hands` 请求体包含 `table_location` 和 `table_dynamic` 字段。

3. **API 直测**：
   ```bash
   curl -X POST /api/poker/hands \
     -H "X-Anon-Token: test-uuid" \
     -H "Content-Type: application/json" \
     -d '{"blind_level":"1/2","table_type":"6max","hero_position":"BTN","hero_cards":"AsKd","preflop_actions":"BTN raise","table_location":"offline","table_dynamic":"loose_passive"}'
   ```
   响应应返回 `{"hand_id": N}`，无报错。

4. **AI 分析上下文验证**：对上一步录入的手牌发起分析请求，确认后端日志中 `buildHandContext` 输出文本包含 `拍桌: 线下` 和 `桌面动态: 松浪` 两行。

5. **向后兼容确认**：查询已有手牌（`table_location` 和 `table_dynamic` 均为 null），AI 分析上下文不应出现这两行。
